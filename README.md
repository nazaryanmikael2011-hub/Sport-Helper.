# SPORT HELPER — Элитный фитнес-трекер и лайфстайл помощник

Современное веб-приложение на React для спорта, правильного питания и здорового образа жизни. Разработано с соблюдением Mobile-first подхода, полностью адаптивно (смартфоны, планшеты, ноутбуки, десктопы) с премиальным кибер-атлетическим темным дизайном, акцентами в неоново-зеленом (`#00FF85`) и оранжевом (`#FF5E00`) цветах, плавными анимациями Framer Motion и звуко-визуальными эффектами победы (конфетти).

## ⚡ Главные функциональные модули

### 1. Загрузка фото профиля (Аватар на ПК и смартфонах)
- **Интерактивный блок аватара в Dashboard и Профиле** ([`AvatarUploader.jsx`](file:///c:/Users/Konstantin/Desktop/Sport-Helper/src/components/profile/AvatarUploader.jsx)):
  - Круглая аватарка с неоновым обрамлением и полупрозрачным оверлеем с иконкой фотоаппарата и надписью «Изменить фото» (появляется при наведении на десктопе, всегда видна внизу круга на мобильных устройствах).
  - Под аватаром расположена яркая неоново-зеленая кнопка **«Загрузить из галереи»**.
- **Адаптивный мобильный опыт (Mobile Bottom Sheet)**:
  - На смартфонах (экран < 768px) клик по аватару или кнопке открывает анимированное нижнее меню (Bottom Sheet) с тремя опциями:
    1. 📷 **«Сделать фото»** — прямое открытие камеры устройства (`capture="user"`).
    2. 🖼️ **«Выбрать из галереи»** — акцентная неоновая кнопка с выбором изображения из галереи телефона.
    3. 🗑️ **«Удалить текущее»** — кнопка красного цвета для сброса аватара на дефолтный.
  - На десктопе (экран ≥ 768px) нажатие сразу вызывает стандартный диалог выбора файлов операционной системы.
- **Мгновенное сохранение**: фото моментально подставляется в интерфейс через `URL.createObjectURL` и кодируется в base64 через `FileReader` с автоматическим сохранением в `localStorage`, поэтому аватар не сбрасывается при перезагрузке страницы.

### 3. Пошаговая регистрация (Onboarding Flow) при первом входе
- **Экран первого входа («Добро пожаловать в SPORT HELPER»)** ([`WelcomeScreen.jsx`](file:///c:/Users/Konstantin/Desktop/Sport-Helper/src/components/auth/WelcomeScreen.jsx)):
  - Отображается при отсутствии данных пользователя в `localStorage` (или при нажатии «Сбросить демо» / «Выйти»).
  - Презентует ключевые возможности платформы с быстрым доступом к демо-аккаунту («Войти с демо-профилем») и кнопкой старта регистрации.
- **Пошаговый мастер регистрации с Framer Motion анимациями скольжения слайдов** ([`OnboardingFlow.jsx`](file:///c:/Users/Konstantin/Desktop/Sport-Helper/src/components/auth/OnboardingFlow.jsx)):
  - **Шаг 1: Создание аккаунта**: Имя атлета, Email, Пароль с индикатором безопасности.
  - **Шаг 2: Физические показатели**: Плавные ползунки (Range Sliders) и числовые инпуты: **Возраст** (16–75 лет), **Текущий вес** (45–150 кг), **Целевой вес** (45–150 кг), **Рост** (140–215 см). Динамический расчет ИМТ (BMI).
  - **Шаг 3: Выбор фокуса**:
    1. 🔥 **«Похудение»** (дефицит 20% ккал, HIIT, кардио).
    2. 💪 **«Набор массы»** (профицит 15% ккал, гипертрофия).
    3. 🤸‍♂️ **«Силовые элементы и калистеника»** (воркаут, L-sit, Tuck Planche, выходы силой, 2.3г белка/кг).
- **Завершение онбординга**: начисление +100 XP, запуск конфетти и мгновенный переход на Дашборд.

## 🛠 Технологический стек

- **React 18** (функциональные компоненты, кастомные хуки, Context API с автосохранением в `localStorage`).
- **Tailwind CSS 3** (кастомная неоновая темная палитра, стекломорфизм `glass-card`, адаптивная сетка).
- **Framer Motion** (плавные скользящие переходы слайдов онбординга, выезжающий снизу Bottom Sheet, модальные окна, анимация SVG-кругов и жестов).
- **Lucide React** (современный набор спортивных и UI иконок).
- **Canvas-Confetti** (празднование завершения подходов, тренировок и новых уровней).
- **Vite 6** (молниеносная сборка и HMR).

## 🚀 Запуск проекта

1. Установка зависимостей:
```bash
npm install
```

2. Запуск локального сервера разработки:
```bash
npm run dev
```
Приложение доступно по адресу `http://localhost:3000/`.

3. Сборка для продакшена:
```bash
npm run build
```
